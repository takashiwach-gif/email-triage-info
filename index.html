Discord Email Brief

A personal email-triage tool for its owner's Gmail account. It runs on a schedule in GitHub Actions and delivers a short private Discord brief of messages that may need attention.

What it does

  • Reads metadata and snippets of unread inbox messages.
  • Uses Google Gemini to classify messages using the owner's triage rules.
  • Adds existing Gmail labels and sends selected message previews and Gmail links to the owner's Discord direct messages.
  • The script does not mark messages read, send email replies, or delete email.

This is a personal-use app, not a public email service. There is no public registration.
