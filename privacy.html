Privacy and data use

Updated October 20, 2026. Discord Email Brief is a personal-use automation for the owner's Gmail account.

Data accessed and purpose

The script reads unread inbox message IDs, sender headers, subjects, snippets, and Gmail labels to identify messages that may need the owner's attention. It adds existing labels to support inbox organization. With owner authorization, it can mark obvious non-job bulk newsletters, promotions, and digests read. It keeps job-related, attention-needed, starred, important, personal-reply, and uncertain messages unread. It does not delete messages or send email replies.

Where data goes

  • Google Gmail provides the inbox metadata and accepts label updates.
  • Google Gemini receives sender, subject, and snippet content for classification. Processing and retention by Google depend on the Gemini API service terms and account tier.
  • Discord receives selected sender names, subjects, short snippets, and Gmail links in a direct message to the owner. The script also reads earlier direct-message history to reduce duplicate alerts.
  • GitHub Actions runs the script. Workflow logs record execution information and may contain error diagnostics. OAuth and API credentials are supplied through repository secrets and are not intended for model prompts or Discord messages.

Retention and control

Each completed classification run saves a private audit report in the private GitHub repository Actions artifacts for seven days. This report includes sender, subject, message IDs, classification decisions, and IDs of messages marked read, enabling review and restoration. It contains no authentication credentials. The source code does not maintain a separate email database. Gmail retains the original messages; Discord retains brief messages until removed under its service controls. GitHub retains workflow logs according to the repository's retention settings. Each service processes data under its own terms. Stopping scheduled runs stops future processing. The owner can revoke the app's Google access through Google Account connections and remove stored repository secrets and Discord messages.

Scope of this app

The app is operated for its owner's personal use and has no public signup, advertising, or sale of inbox data. This information page does not request access to Gmail and does not collect visitor email content.
